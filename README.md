# LLM Service

LLM + MCP-сервер.
Для OpenRouter и локальной Ollama

---

## Структура проекта

### `common/`
- Настройки (получение данных из `.env`)
- Промпты (черновая версия)

---

### `models/`
- Конфигурация LLM
- Формат запроса к LLM

---

### `providers/`
Содержит два класса инициализации LLM:
- Локальная модель (Ollama)
- Удалённая модель (OpenRouter)

Функциональность:
- Получают конфигурацию LLM
- Инициализируют подключение к модели
- Отправляют запрос (chat_completion)
- Конвертируют инструменты в поддерживаемый формат (_convert_tools_to_ollama_format)
- Парсят полученный ответ (_parce_response)
- Вызывают инструменты (_tool_call)

---

### `clients/`
MCP-клиент. Содержит:
- Подключение к mcp-серверу (connect_mcp)
- Закрытие соединения с mcp-сервером (close)
- Отправку сообщения ЛЛМ (chat_completion)
- Вызывает инструменты (_tool_call)

---

### `app/`
Эндпоинт для отправки сообщения. В нем устанавливается соединение с сервером, отправляется запрос ЛЛМ, прекращается соединение с сервером

---

### `mcp_module/`
MCP-сервер. Содержит в себе:
- модели (all_models.py)
- классы с методами для тулзов (services.py)
- моки (storage.py)

---

### `main.py`
- Инициализация FastAPI-приложения
- Подключение роутера
- Настройка логирования
- Корневой эндпоинт

---

### `server.py`
Сам MCP-сервер. Инициализация сервера и тулзов.
