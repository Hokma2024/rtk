# LLM Service

Сервис для работы с LLM (локальной и удалённой).

LLM получает запрос в формате текста и возвращает:
- `content` — текстовый ответ модели
- `tool_calls` — список инструментов, выбранных нейросетью для решения запроса

Код адаптируется как под локальную LLM (Ollama), так и под удалённую (OpenRouter).

---

## Структура проекта

### `common/`
- Настройки (получение данных из `.env`)
- Промпты (черновая версия)

---

### `models/`
- Конфигурация LLM
- Формат ответа от LLM (пока не используется, но добавлен на всякий случай)
- Формат запроса к LLM

---

### `providers/`
Содержит два класса инициализации LLM:
- Локальная модель (Ollama)
- Удалённая модель (OpenRouter)

Функциональность:
- Получают конфигурацию LLM
- Инициализируют подключение к модели

---

### `repositories/`

#### `llm_repository`
- Функции подключения к LLM
- Формирование массива сообщений для отправки в модель (именно формирование конечных готовых сообщений - системного и пользовательского)

`openrouter_repository`
На данный момент не используется. Оставлен временно, на всякий случай.

---

### `service/`
- Функция подключения (через `llm_repository`)
- Первичная функция создания сообщений (разделение сообщений на системное и пользовательское. Добавление соответствующих ролей, промпта и самого запроса)

---

### `controllers/`
- Эндпоинты для:
  - Инициализации подключения к LLM
  - Отправки запроса модели
- Объявляется кастомный роутер с префиксом

---

### `tools/`
Временные инструменты.

Используется декоратор `@tools` из LangChain, удобно.

---

### `main.py`
- Инициализация FastAPI-приложения
- Подключение роутера
- Настройка логирования
- Корневой эндпоинт

---
